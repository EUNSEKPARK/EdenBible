## 1. 성경 전문 검색

**파일:** `lib/features/bible_reader/views/search_view.dart`
**진입 경로:** 상단 앱바 🔍 검색 아이콘 탭

### 기능 상세

검색 화면에 진입하면 키보드가 자동으로 올라오며, 텍스트를 입력하고 검색 버튼을 누르면 개역한글 성경 전체(66권, 27,121절)에서 키워드를 검색합니다. 최대 100개 결과를 반환하며, 검색어에 해당하는 부분이 Sage Green 색상으로 하이라이트 표시됩니다.

검색 전에는 인기 검색어 10개(사랑, 평안, 소망, 믿음, 은혜, 기도, 용서, 감사, 지혜, 축복)가 칩 형태로 표시되어 탭하면 바로 검색됩니다.

각 검색 결과에는 구절 참조(예: "요한복음 3:16"), 카테고리 태그(예: "복음서"), 그리고 본문 텍스트가 표시됩니다.

### 기술 구현

BibleDataService의 `search()` 메서드를 사용하여 모든 구절의 KRV 텍스트에서 `contains()` 매칭을 수행합니다. 비동기 `Future.microtask()`로 처리하여 검색 중에도 UI가 멈추지 않습니다.

## 2. TTS 음성 읽기

**파일:** `lib/core/services/tts_service.dart`
**진입 경로:** 성경 읽기 화면 하단 플로팅 바의 ▶ 재생 버튼

### 기능 상세

재생 버튼을 탭하면 현재 보고 있는 장의 전체 구절을 음성으로 읽어줍니다. 개역한글 모드에서는 한국어 TTS가, KJV 모드에서는 영어 TTS가 자동으로 적용됩니다.

재생 중에 다시 탭하면 음성이 중지됩니다.

### 기술 구현

`flutter_tts` 패키지를 사용하며, 싱글톤 패턴으로 앱 전체에서 하나의 TTS 인스턴스를 공유합니다. 기본 음성 속도는 0.45(자연스러운 읽기 속도), 피치는 1.0으로 설정되어 있습니다.

현재 번역본 설정에 따라 `setLanguage('ko-KR')` 또는 `setLanguage('en-US')`가 자동 전환됩니다.

### 지원 기능

- 전체 장 연속 읽기 (`speakVerses`)
- 개별 구절 읽기 (`speak`)
- 재생/중지 토글
- 속도 조절 (0.1 ~ 1.0)
- 한국어/영어 자동 전환

## 3. SNS 공유 카드

**파일:** `lib/shared/widgets/share_verse_card.dart`
**진입 경로:** 성경 읽기 화면 하단 플로팅 바의 공유(↗) 아이콘, AI 상담 메시지 하단 공유 아이콘

### 기능 상세

공유 아이콘을 탭하면 BottomSheet가 올라오며, 예쁜 Sage Green 그라데이션 카드에 성경 구절이 담긴 미리보기가 표시됩니다. 카드에는 구절 텍스트, 참조(책/장:절), "에덴 - AI 성경책" 워터마크가 포함됩니다.

AI 상담에서 공유하는 경우, 카드에 AI의 따뜻한 메시지도 함께 포함됩니다.

두 가지 공유 방식을 제공합니다. "이미지로 공유하기"는 카드를 PNG 이미지로 캡처하여 인스타그램, 카카오톡 등에 바로 공유하며, "텍스트로 공유하기"는 구절 텍스트와 참조를 텍스트 형태로 공유합니다.

### 기술 구현

`RepaintBoundary`와 `toImage()`를 사용하여 위젯을 3배 해상도 PNG로 캡처합니다. 캡처된 이미지는 임시 디렉토리에 저장된 후 `share_plus` 패키지의 `Share.shareXFiles()`로 시스템 공유 시트에 전달됩니다.

### 카드 디자인

- 배경: Sage Green → Primary Dark 그라데이션
- 상단: "에덴" 라벨 (작은 라인 + 텍스트)
- 중앙: 성경 구절 (22pt, 흰색, 따옴표 포함)
- 하단 참조: Warm Gold 색상
- AI 메시지 (선택): 반투명 흰색 배경 카드 내 이탤릭 텍스트
- 워터마크: "에덴 - AI 성경책" (우하단, 투명도 40%)

## 4. 성경 필사

**파일:** `lib/features/transcription/views/transcription_view.dart`
**진입 경로:** 홈 화면 "필사" 아이콘 메뉴 탭

### 기능 상세

필사 화면에 진입하면 상단에 원문 구절이 표시되고, 하단에 입력 영역이 나타납니다. 사용자는 원문을 보면서 직접 타이핑하여 필사합니다. "다음 절로 →" 버튼을 누르면 자동으로 다음 절로 넘어가고, 마지막 절까지 완료하면 결과 화면이 표시됩니다.

결과 화면에는 필사한 절 수, 정확도(퍼센트), 정확 일치 수가 통계로 표시됩니다.

상단의 교체 아이콘(⇄)을 탭하면 필사할 장을 선택하는 BottomSheet가 나타나며, 시편 23편, 고린도전서 13장 등 10개의 인기 장이 추천 목록으로 제공됩니다.

### 정확도 판정 방식

입력 텍스트와 원문을 비교할 때 공백, 마침표, 쉼표, 느낌표 등 구두점을 제거한 후 비교합니다. 이렇게 하면 구두점 차이로 인한 불필요한 오답 판정을 방지합니다.

### 추천 필사 목록 (10개)

시편 23편, 시편 91편, 시편 121편, 잠언 3장, 전도서 3장, 이사야 40장, 마태복음 5장 (산상수훈), 요한복음 1장, 고린도전서 13장 (사랑장), 빌립보서 4장

### 화면 구성

- 상단: 진행률 바 (절/전체 + 퍼센트)
- 중앙 상단: 원문 표시 카드 (절 번호 + 참조 + 본문)
- 중앙 하단: 필사 입력 영역 (텍스트 필드)
- 하단: "다음 절로" 버튼
- 완료 화면: 체크 아이콘 + 통계 3종 + "다시 필사하기" 버튼

## 5. 성경 연구 (대조 보기)

**파일:** `lib/features/deep_study/views/study_view.dart`
**진입 경로:** 홈 화면 "성경 연구" 아이콘 메뉴 탭

### 기능 상세

현재 창세기 1:1-3을 기준으로 개역한글과 KJV를 좌우(모바일에서는 상하) 대조 보기로 표시합니다. 원어 주요 단어에는 밑줄이 표시되어 있으며, 하단에 주석 및 통찰 영역이 있습니다.

주석 영역에는 AI 강해(히브리어 '바라' 단어 해설), 교차 참조(요한복음 1:1, 시편 33:6) 등이 포함됩니다.

### 현재 제한사항

현재 버전은 창세기 1:1-3의 하드코딩된 데이터를 사용합니다. 추후 BibleDataService와 연동하여 사용자가 선택한 구절에 대해 동적으로 대조 보기를 제공하도록 확장할 수 있습니다.
