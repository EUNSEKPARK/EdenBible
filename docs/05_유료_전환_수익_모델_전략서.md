### 1-2. 에덴의 차별화 포지션

```
경쟁 구도:

YouVersion (무료 거대 플랫폼)
  ↕ 에덴이 이길 수 없는 영역: 번역본 수, 사용자 규모, 커뮤니티
  
에덴 성경책이 이길 수 있는 영역:
  ✅ "눈·귀·이미지" 올인원 경험 (경쟁사 없음)
  ✅ 오프라인 완전 동작 (데이터 부담 없음)
  ✅ 회원가입 없음 (진입 장벽 최소)
  ✅ AI 맞춤 상담 (온디바이스)
  ✅ 넷플릭스 스타일 "보는 성경" (완전히 새로운 카테고리)
```

### 1-3. 2025~2026 구독 앱 시장 벤치마크 (RevenueCat 리포트 기준)

| 지표 | 업계 평균 | 상위 앱 | 에덴 목표 |
|------|---------|--------|---------|
| 프리미엄 전환율 (Day 35) | 2~5% | 5~10% | 3~5% |
| 무료 체험 시작률 | 45% (프리미엄) / 78% (하드 페이월) | — | 50%+ |
| 체험 → 유료 전환 | 40~60% | 70%+ | 50% |
| 월간 이탈률 (Churn) | 8~12% | 5% 이하 | 8% 이하 |
| 연간 플랜 비율 | 60~70% | 80%+ | 70% |

> **핵심 인사이트:** 하드 페이월이 프리미엄보다 전환율이 5배 높지만(10.7% vs 2.1%), 성경 앱은 "말씀 접근성"이 본질적 가치이므로 **프리미엄 모델이 더 적합**합니다. 무료 사용자가 입소문을 내고, 프리미엄 기능의 체험이 자연스럽게 전환으로 이어지게 설계해야 합니다.

## 3. 전환 퍼널 설계

### 3-1. 사용자 여정 전체 흐름

```
[설치] → [온보딩] → [무료 사용] → [가치 인식] → [체험 유도] → [구독 전환]
  ↓         ↓          ↓            ↓            ↓            ↓
100%      95%       80%~90%      40%~50%      20%~30%       3%~5%
```

#### 단계 2: 무료 사용 중 — 가치 체험 (Day 1~6)

무료 사용 중에 프리미엄 기능의 매력을 자연스럽게 보여줍니다.

**번들 체험 콘텐츠:**
- TypeCast 음성: 18장 무료 (창세기 1~3, 시편 23/91/121, 마태 5~7, 요한 1/3/14 등)
- 보는 성경: 창세기 1장 + 시편 23편만 체험 가능
- 공유 카드: 기본 1종 (프리미엄 카드 미리보기는 워터마크 포함)

**체험 트리거 포인트:**
| 사용자 행동 | 표시되는 프리미엄 유도 |
|-----------|---------------------|
| TTS 재생 버튼 탭 (번들 외 장) | "이 장을 전문 성우 음성으로 들어보세요" + 5초 미리듣기 |
| 보는 성경 탭 (잠금 장) | 블러 이미지 + "7일 무료 체험으로 보는 성경을 경험하세요" |
| 10장 이상 읽기 달성 | "축하합니다! 듣는 성경으로 통독 속도를 높여보세요" |
| AI 상담 5회 이상 사용 | "더 다양한 상담 주제가 준비되어 있어요" |
| 공유 카드 생성 시 | 프리미엄 카드 3종 미리보기 (워터마크) |

#### 단계 3: 무료 체험 종료 — 전환 결정 (Day 7)

## 4. 전환 트리거 — 언제, 어디서 페이월을 보여줄 것인가

### 4-1. 전환 트리거 맵

"기능에 닿았을 때" 자연스럽게 보여주는 것이 핵심입니다. 사용을 방해하는 느낌이 들면 안 됩니다.

| 트리거 | 위치 | 형태 | 빈도 제한 |
|--------|------|------|----------|
| **TypeCast 재생 시도** (잠금 장) | 성경 읽기 → 재생 버튼 | 바텀시트 (5초 미리듣기 포함) | 1일 1회 |
| **보는 성경 모드 전환** (잠금) | 모드 전환 토글 | 바텀시트 (블러 미리보기) | 제한 없음 (탭할 때마다) |
| **공유 카드 프리미엄 템플릿** | 공유 시트 | 인라인 잠금 아이콘 | 제한 없음 |
| **연속 읽기 7일 달성** | 홈 화면 배지 | 축하 + 업그레이드 제안 | 1회성 |
| **통독 10% 달성** | 진행률 카드 | 축하 + "듣기로 가속" 제안 | 1회성 |
| **앱 내 설정** | 설정 → 에덴 프리미엄 | 상시 노출 배너 | 항상 표시 |
| **앱 열기 (비활성 7일 후)** | 스플래시 후 | 특별 할인 오퍼 | 1회 |

### 4-2. 절대 하지 말아야 할 것

| 금지 사항 | 이유 |
|----------|------|
| 성경 본문 읽기를 막지 않음 | 성경 접근성은 에덴의 핵심 가치 |
| AI 상담을 완전히 잠그지 않음 | 무료 사용자에게도 기본 상담 50개 유지 |
| 전체화면 팝업 강제 표시 | 사용자 이탈 유발, 부정적 리뷰 원인 |
| 하루에 여러 번 페이월 표시 | 피로감 → 삭제 |
| 읽기 도중 페이월 끼어넣기 | 묵상/기도 중 방해 → 최악의 경험 |
| 무료 체험 강제 (결제 정보 필수) | 성경 앱 사용자층이 민감 |

### 5-3. 구독 상태 관리

```dart
/// 구독 상태 enum
enum SubscriptionTier {
  free,           // 무료
  premium,        // 프리미엄 (듣는 성경)
  premiumPlus,    // 프리미엄+ (보는 성경)
  trial,          // 무료 체험 중
}

/// 구독 서비스
class SubscriptionService extends ChangeNotifier {
  SubscriptionTier _tier = SubscriptionTier.free;
  DateTime? _trialEndDate;
  
  bool get canListenTypecast => 
    _tier == SubscriptionTier.premium || 
    _tier == SubscriptionTier.premiumPlus ||
    _tier == SubscriptionTier.trial;
  
  bool get canWatchVisualBible => 
    _tier == SubscriptionTier.premiumPlus ||
    _tier == SubscriptionTier.trial;
  
  bool get isTrialing => 
    _tier == SubscriptionTier.trial &&
    _trialEndDate != null &&
    DateTime.now().isBefore(_trialEndDate!);
  
  /// 번들 체험 콘텐츠 접근 가능 여부
  bool canAccessBundledContent(int bookId, int chapter) {
    // 무료 사용자도 번들 18장은 TypeCast 체험 가능
    return _bundledChapters.contains('${bookId}_$chapter');
  }
}
```

**짧은 설명 (80자):**

```
오프라인 성경 66권 + 전문 성우 음성 + 넷플릭스 스타일 보는 성경
```

**핵심 키워드:**

```
성경, 성경앱, 오디오성경, 성경읽기, 말씀, 큐티, 개역한글,

```

**스크린샷 구성 (8장):**
1. "눈으로 읽고, 귀로 듣고, 이미지로 보는 성경" (핵심 가치)
2. 읽는 성경 화면 (깔끔한 본문 뷰)
3. 듣는 성경 화면 (TypeCast 재생 + 구절 하이라이트)

5. AI 말씀 상담 화면
6. 오늘의 말씀 + 연속 읽기
7. SNS 공유 카드
8. 다크 모드 화면

### 6-4. 이탈 방지 (Churn 관리)

| 시점 | 액션 |
|------|------|
| 구독 갱신 3일 전 | "이번 달 N장을 TypeCast로 들으셨어요" 가치 요약 |
| 구독 취소 시도 시 | 취소 이유 설문 + 대안 제안 (다운그레이드, 일시정지) |
| 결제 실패 시 | Grace period 3일 + 결제 수단 갱신 안내 |
| 취소 후 7일 | "보는 성경이 그리우신가요?" + 50% 할인 윈백 오퍼 |
| 취소 후 30일 | "에덴에 새로운 기능이 추가되었어요" 재가입 유도 |

### 6-5. 구글 플레이 결제 실패 대응

RevenueCat 2026 리포트에 따르면, 구글 플레이 구독 취소의 **약 30%가 비자발적 결제 실패**입니다 (앱 스토어의 2배). 이를 해결하면 사실상 "공짜 성장"입니다.

| 대응 | 구현 |
|------|------|
| Grace Period 설정 | 구글 플레이 콘솔에서 3~7일 유예 기간 |
| Account Hold | 결제 실패 시 구독 일시정지 (최대 30일) |
| 인앱 결제 수단 갱신 안내 | "결제를 업데이트해 주세요" 배너 표시 |
| 재시도 알림 | 결제 실패 후 3일/7일에 푸시 알림 |

## 9. 핵심 전략 요약

### 무료 사용자를 소중히

성경 본문 읽기, AI 상담, 기본 TTS는 영원히 무료. "말씀 접근성"을 절대 막지 않습니다. 무료 사용자가 교회에서, 카카오톡에서, SNS에서 에덴을 퍼뜨려 줍니다.

### "체험"이 최고의 영업

번들 18장 TypeCast 음성 + 창세기 1장 보는 성경 체험으로 "이 품질을 계속 듣고 싶다"는 욕구를 만듭니다. 7일 무료 체험은 결제 정보 없이 시작하여 부담을 최소화합니다.

### 절대 성경 읽기를 방해하지 않기

기도 중, 묵상 중, 통독 중에 페이월이 끼어들면 최악입니다. 프리미엄 유도는 "기능에 닿았을 때"만, "사용을 끊는 형태"가 아닌 "더 나은 경험을 제안하는 형태"로 합니다.

### 데이터로 최적화

출시 후 RevenueCat 대시보드로 전환율, 체험 시작률, 이탈률을 추적하고, A/B 테스트로 가격/페이월/체험 기간을 최적화합니다.
