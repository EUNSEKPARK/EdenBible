## 생성 후 처리 명령어

```bash
# 1. Midjourney에서 upscale 후 PNG 다운로드
# 파일명: 01_genesis.png ~ 66_revelation.png

# 2. WebP 변환 + 리사이즈 (480×640)
# macOS: brew install webp
for i in $(seq -w 1 66); do
  cwebp -q 75 -resize 480 640 "raw/${i}_*.png" -o "assets/images/books/${i}.webp"
done

# 3. 결과 확인
ls -la assets/images/books/
# 각 파일 ~80~200KB, 총 66개, 합계 ~8~13MB
```
