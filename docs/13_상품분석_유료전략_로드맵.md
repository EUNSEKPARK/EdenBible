## PART 1. 상품 정밀 분석

### 1-1. 경쟁 환경

| 앱 | 다운로드 | 특징 | 약점 |
|---|---------|------|------|
| 갓피플성경 | 100만+ | 통독모임, 원어사전, 채널, 10년 역사 | UI 구식, 다크모드 미흡, 유료 역본 多 |
| 바이블 애플 | 500만+ | 21개 역본, 오디오, 찬송가 | 용량 큼, 무료지만 광고 有 |
| 대한성서공회 | 100만+ | 공식 역본, 해설관주 | UI 매우 구식, 지원기기 제한 |
| YouVersion | 5억+ | 글로벌 1위, 묵상계획 | 한국어 콘텐츠 부족, 항상 인터넷 필요 |
| 초원 성경 | 10만+ | AI 질문 기능 (GPT 기반) | AI가 유료, 가격 높음, 오프라인 불가 |

### 1-2. 에덴 성경책 SWOT

**강점**
- 완전 오프라인 동작
- 감정별 맞춤 힐링 (10감정 × 35상황) — 타 앱에 없는 독자 기능
- 수면 묵상 모드 (타이머 + 다크 UI + TTS)
- 본인 유튜브 채널 100개 영상 연동 (저작권 무료)
- 개역한글 + KJV 이중 번역 (저작권료 0원)
- 광고 없음 + 모던 UI/UX

**약점**
- 개역개정 미포함 (한국 교회 표준 역본)
- 검색/주석/원어사전 없음
- 커뮤니티 기능 없음
- 신규 앱 인지도 0
- 1인 개발 한계

**기회**
- "AI + 성경" 트렌드 (초원 성경이 시장 수요 증명)
- Z세대 크리스천 (감성 UI + 힐링에 반응)
- 유튜브 채널 시너지 (앱 ↔ 유튜브 교차 유입)
- KJV 포함 → 영어권 글로벌 확장 가능

**위협**
- 갓피플 10년 독점 + 바이블애플 500만 다운로드
- AI 성경 앱 (초원, ChatGPT 연동) 확산

### 1-3. 상품 평가 (5점 만점)

| 항목 | 점수 | 평가 |
|------|------|------|
| UI/UX 디자인 | 4.5 | 경쟁 앱 대비 가장 세련됨 |
| 핵심 기능 완성도 | 4.0 | 성경 읽기 + TTS + 북마크 + 공유 |
| 차별화 기능 | 5.0 | 감정 힐링 + 수면 묵상 + 유튜브 = 유일무이 |
| 콘텐츠 깊이 | 3.0 | 해설/주석/원어사전 없음 |
| 수익화 준비 | 2.0 | 프리미엄 "준비 중"만 존재 |
| 마케팅 연동 | 4.0 | 유튜브 101개 영상 = 강력한 자산 |
| **종합** | **3.75** | 상품성 우수, 수익화가 다음 단계 |

## PART 2. 유료 전환 전략

### 2-1. 추천 모델: 프리미엄(Freemium)

성경 본문은 무료 (시장 표준) + 부가 기능을 구독으로 제공

### 2-2. 무료 vs 프리미엄

| 기능 | 무료 (영원히) | 프리미엄 |
|------|-------------|---------|
| 성경 66권 (개역한글+KJV) | ✅ | ✅ |
| TTS 음성 읽기 | 1.0x만 | 전체 배속 |
| 북마크 | 30개 제한 | 무제한 |
| 감정 힐링 | 하루 3회 | 무제한 |
| 수면 묵상 | 15분만 | 15/30/60분+커스텀 |
| 유튜브 추천 | 오늘의 3개만 | 전체 100개+카테고리 |
| 테마 | 라이트만 | 다크+시스템 |
| 말씀 상담 | 하루 5회 | 무제한 |
| 말씀 카드 공유 | 기본 | 프리미엄 템플릿 5종 |
| 광고 | 없음 | 없음 |

### 2-3. 가격

| 플랜 | 가격 | 비고 |
|------|------|------|
| 월간 구독 | ₩3,900 | 커피 한 잔 |
| 연간 구독 | ₩29,900 (월 ₩2,492) | 36% 할인 |
| 평생 이용권 | ₩59,900 | 초기 한정 |

### 2-4. 전환 타이밍

- 1~3개월: 완전 무료 (다운로드 5,000건 + 리뷰 100개 목표)
- 4~6개월: 소프트 프리미엄 (7일 무료 체험 + 초기 50% 할인)
- 7개월~: 본격 프리미엄 (무료 제한 적용)

## PART 3. 추가 기능 로드맵

### v1.1 (출시 후 1개월)
- 성경 키워드 전문 검색 + 하이라이트
- 오늘의 말씀 알림 (flutter_local_notifications)
- 읽기 플랜 (1년/6개월/3개월 통독 계획 + 체크리스트)
- 말씀 카드 이미지 저장

### v1.5 (출시 후 3개월) — 프리미엄 기능
- 실제 AI 상담 (온디바이스 LLM: Gemma 2B)
- 프리미엄 공유 템플릿 5종
- 주간/월간 읽기 리포트
- 성경 필사 모드
- 잠언 음성 묵상 연동 (유튜브 낭독 자동 연결)

### v2.0 (출시 후 6개월) — 커뮤니티 + 확장
- 통독 모임 (소그룹 진행률 공유)
- 묵상 노트 (절별 메모 + 검색)
- 오디오 성경 (TypeCast 전문 성우)
- 개역개정 추가 (대한성서공회 라이선스)
- 영어 UI + 글로벌 출시
- 홈 화면 위젯 (오늘의 말씀)

### 우선순위: 쉬움+효과 높음 먼저
1순위: 읽기 플랜, 검색 강화, 알림
2순위: AI 상담, 필사 모드, 프리미엄 템플릿
3순위: 통독 모임, 오디오 성경, 개역개정, 글로벌
