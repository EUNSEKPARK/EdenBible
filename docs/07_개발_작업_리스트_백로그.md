### ═══ Phase 1: MVP 핵심 (2~3주) ═══

#### 🟥 P0-01: emotion_map.json 데이터 작성
- **설명:** 버튼형 AI의 핵심 데이터. 10개 감정 × 3~4개 상황 = 35개 매칭 세트
- **산출물:** `assets/data/emotion_map.json` (~200KB)
- **포맷:**
  ```json
  {
    "categories": [
      {
        "id": "anxiety", "emoji": "😔", "label": "불안", "color": "#7B8FA1",
        "situations": [
          {
            "id": "anxiety_future", "label": "미래에 대한 걱정", "icon": "hourglass_empty",
            "response": {
              "ai_message": "위로 메시지...",
              "verses": [{"ref": "예레미야 29:11", "book_id": 24, "chapter": 29, "verse": 11}],
              "prayer_guide": "기도문...",
              "youtube_curated": [{"title": "제목", "video_id": "abc123"}]
            }
          }
        ]
      }
    ]
  }
  ```
- **10개 감정 카테고리:**
  1. 😔 불안 (미래걱정, 경제, 건강, 시험/진로, 가족걱정)
  2. 😢 슬픔 (상실, 외로움, 실패감, 배신)
  3. 💔 관계 (가족갈등, 친구문제, 교회갈등, 용서)
  4. 🙏 감사 (일상감사, 기도응답, 회복감사)
  5. 😤 분노 (불의, 상처, 자기분노)
  6. 😴 지침 (번아웃, 영적메마름, 과부하)
  7. 🌙 수면 (걱정, 생각과다, 평안필요)
  8. 😊 기쁨 (찬양, 간증)
  9. ❓ 방향상실 (진로, 신앙회의, 삶의의미)
  10. 💪 용기 (새도전, 중요결정, 전도)
- **작업량:** 35개 상황 × (AI메시지 + 구절2개 + 기도문 + 유튜브2개) = 엑셀 정리 → JSON 변환
- **참고:** 기존 counsel_presets.json의 50개 프리셋을 재활용 가능
- **예상 시간:** 3~5일 (콘텐츠 작성이 대부분)

#### 🟥 P0-02: EmotionMatchService 구현
- **설명:** emotion_map.json을 로드하고 매칭하는 서비스
- **산출물:** `lib/core/services/emotion_match_service.dart`
- **주요 메서드:**
  ```dart
  class EmotionMatchService extends ChangeNotifier {
    Future<void> load();                              // JSON 로드
    List<EmotionCategory> get categories;             // 10개 감정 목록
    List<Situation> getSituations(String categoryId); // 세부 상황 목록
    HealingResponse getResponse(String situationId);  // 힐링 패키지
    HealingResponse? getAlternative(String catId, String excludeId); // 다른 말씀
  }
  ```
- **모델 파일:**
  - `lib/core/models/emotion_category.dart`
  - `lib/core/models/situation.dart`
  - `lib/core/models/healing_response.dart`
- **예상 시간:** 1일

#### 🟥 P0-03: 감정 선택 3화면 UI 구현
- **설명:** 버튼형 AI의 핵심 UI 흐름 (기존 채팅형 counsel_view.dart 대체 또는 병행)
- **산출물:** 3개 Dart 파일
- **파일 구조:**
  ```
  lib/features/healing/views/
  ├── emotion_category_view.dart    # 1단계: 감정 대분류 (10개 이모지 카드)
  ├── situation_view.dart           # 2단계: 세부 상황 (3~5개 버튼)
  └── healing_package_view.dart     # 3단계: 힐링 패키지 (위로+말씀+유튜브+기도)
  ```
- **1단계 UI:** 2×5 그리드, 각 카드에 이모지 + 라벨 + 고유 색상
- **2단계 UI:** 리스트 타일, 각 항목에 아이콘 + 라벨
- **3단계 UI:** 스크롤 가능한 단일 화면
  - AI 위로 메시지 카드 (상단)
  - 성경 구절 카드 1~2개 (복사/공유 버튼 포함)
  - 유튜브 추천 가로 스크롤 (썸네일 카드)
  - 기도 가이드 카드 (하단)
  - [다른 말씀 보기] 버튼
- **예상 시간:** 2~3일
