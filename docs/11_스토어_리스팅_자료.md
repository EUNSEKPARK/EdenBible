## Google Play Store 리스팅

### 앱 이름
**에덴 성경책 — 당신을 천국으로 이끄는 성경**

### 짧은 설명 (80자 이내)
오프라인 성경 읽기 + 감정별 AI 힐링 + 수면 묵상. 탭 3번이면 위로받는 성경 앱.

### 긴 설명

📖 에덴 성경책 — 완전 오프라인 성경 앱

인터넷 없이도 사용할 수 있는 성경 앱입니다.
개역한글 + KJV 이중 번역, 감정별 맞춤 힐링, 수면 묵상까지.
당신의 하루를 말씀으로 채워드립니다.

🌿 핵심 기능

▸ 성경 66권 전체 (개역한글 27,121절 + KJV 31,102절)
▸ 리스트 읽기 + 카드 스와이프 읽기 모드
▸ 비주얼 책 선택기 (66권 컬러 카드 그리드)
▸ TTS 음성 읽기 (한국어/영어, 오프라인)
▸ 핀치줌 글자 크기 조절
▸ 구절 북마크 + 공유 카드

💜 마음 힐링 — 탭 3번이면 위로

서버 연결 없이 기기 안에서 바로 작동합니다.
1. 지금 감정 선택 (불안, 슬픔, 관계, 감사 등 10가지)
2. 세부 상황 선택 (미래 걱정, 경제적 어려움 등 35가지)
3. 힐링 패키지 완성!
   — AI 위로 메시지 + 맞춤 성경 구절 + 기도 가이드 + 찬양 추천

🌙 수면 묵상

잠들기 전, 잔잔한 말씀과 함께.
다크 UI + 자동 넘김 + TTS 음성 + 15/30/60분 타이머.
눈을 감고 말씀을 들으며 편안하게 잠드세요.

📊 읽기 여정

통독 진행률 추적, 연속 읽기 스트릭, 최근 읽은 말씀 이어 읽기.

✨ 에덴만의 차별점

• 완전 오프라인 — 비행기에서도, 지하철에서도
• 개인정보 수집 없음 — 모든 데이터는 기기에만 저장
• 광고 없음 — 깨끗한 읽기 환경
• 개역한글 + KJV 즉시 전환
• 감정 패턴 학습 — 자주 찾는 위로 자동 추천
