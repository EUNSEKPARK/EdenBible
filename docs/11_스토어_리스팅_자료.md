### 짧은 설명 (80자 이내)
성경 66권 읽기 + 감정별 맞춤 힐링 + 수면 묵상 + 찬양 추천. 탭 3번이면 위로받는 성경 앱.

### 긴 설명

📖 에덴 성경책

개역한글 + KJV 이중 번역, 감정별 맞춤 힐링, 수면 묵상까지.
당신의 하루를 말씀으로 채워드립니다.

🌿 핵심 기능

▸ 성경 66권 전체 (개역한글 27,121절 + KJV 31,102절)
▸ 리스트 읽기 + 카드 스와이프 읽기 모드
▸ 비주얼 책 선택기 (66권 컬러 카드 그리드)
▸ TTS 음성 읽기 + 실시간 단어 하이라이트 (한국어/영어)
▸ 핀치줌 글자 크기 조절
▸ 처음 사용자를 위한 6페이지 앱 사용 가이드
▸ 구절 북마크 + 공유 카드
▸ 성경 필사 모드
▸ 3개월 / 6개월 / 1년 통독 플랜

💜 마음 힐링 — 탭 3번이면 위로

1. 지금 감정 선택 (불안, 슬픔, 관계, 감사 등 10가지)
2. 세부 상황 선택 (미래 걱정, 경제적 어려움 등 35가지)
3. 힐링 패키지 완성!
   — 맞춤 위로 메시지 + 말씀 추천 + 기도 가이드 + 찬양 추천

💬 말씀 상담

고민이 있을 때, 말씀으로 답을 찾아보세요.
채팅 형식으로 상황을 이야기하면 맞춤 성경 구절과 위로를 전해드립니다.

🌙 수면 묵상

잠들기 전, 잔잔한 말씀과 함께.
다크 UI + 부드러운 페이드 전환 + TTS 음성 + 15/30/60분 타이머.
화면 전환 없이 한 화면에서 말씀이 스르르 바뀌어 눈에 편안합니다.

🎵 은혜의반석 영상 큐레이션

CCM 찬양, 성경 다큐, 애니메이션, 잠언 낭독까지.
8개 테마 × 100개 영상을 넷플릭스 스타일로 탐색하세요.
(영상 재생 시 인터넷 연결 필요)

📊 읽기 여정

통독 진행률 추적, 연속 읽기 스트릭, 최근 읽은 말씀 이어 읽기.
하루 읽기 목표 설정 + 누적 통계.

✨ 에덴만의 차별점

• 성경 읽기, 힐링, 수면 묵상은 인터넷 없이 사용 가능
• 유튜브 영상 탐색/재생 시에만 인터넷 필요
• 개인정보 수집 없음 — 모든 데이터는 기기에만 저장
• 광고 없음 — 깨끗한 읽기 환경
• 개역한글 + KJV 즉시 전환
• 감정별 맞춤 추천 — 자주 찾는 위로 자동 추천
• 다크 모드 지원
