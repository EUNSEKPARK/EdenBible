# 에덴 성경책 — 나만의 특별한 강점 방안

앱 이름·약점 보완과 함께, 구글 플레이에서 차별화할 수 있는 강점 아이디어와 구현 현황을 정리했습니다.

---

## 1. 이미 반영된 차별화

### ① 연속 읽기 일수 (Streak)
- **내용:** 성경을 읽은 날을 연속으로 세어, 홈에 **「연속 N일 읽기 중」** 배지로 표시.
- **효과:** 습관 형성 동기 부여, 다른 성경 앱에서 잘 쓰는 “스트릭”을 에덴만의 톤(말씀·에덴 브랜드)으로 제공.
- **구현:** `SettingsService.streakDays` / `markChapterRead()` 시 갱신, 홈 `_StreakBadge` 위젯.

---

## 2. 추가로 추천하는 차별화 방안

### ② 오늘의 한 구절 잠금화면 / 위젯
- **내용:** “오늘의 말씀”을 홈/잠금화면 위젯 또는 알림으로 노출.
- **효과:** 앱을 열지 않아도 말씀 노출 → 브랜드 각인, 재방문 유도.
- **구현:** `flutter_local_notifications`로 매일 지정 시간에 오늘의 말씀 알림; Android 위젯(홈 화면)은 별도 패키지 검토.

### ③ 말씀 카드 컬렉션 / 성취
- **내용:** “시편 23편 완독”, “복음서 4권 완료” 등 **완독 단위별 배지·카드** 수집.
- **효과:** 통독 동기 부여, 스크린샷·SNS 공유 소재.
- **구현:** `readingProgress` 확장으로 책/구역별 완료 여부 저장, 컬렉션 화면 또는 설정/프로필에 배지 표시.

### ④ 상황별 말씀 상담 강화 (프리셋 확장)
- **내용:** “말씀 상담” 프리셋을 더 세분화(직장, 시험, 건강, 관계 등)하고, 추천 구절 수를 늘림.
- **효과:** “내 상황에 딱 맞는 말씀” 인상 강화, 검색/스토어 키워드(위로, 묵상, 상담) 대응.
- **구현:** `counsel_presets.json` 확장 및 키워드 보강.

### ⑤ 오프라인·무료 강조 문구
- **내용:** 스토어 설명·앱 내 문구에 **“데이터 없이”, “무료 TTS”, “회원가입 없음”** 명시.
- **효과:** 데이터 요금·가입 부담에 민감한 사용자 공략.
- **구현:** 스토어 상세 설명, 스플래시/설정 화면 한 줄 문구 추가.

### ⑥ 공유 카드 템플릿 확장
- **내용:** 배경/폰트/레이아웃을 2~3종으로 선택 가능하게 하거나, 계절/이벤트 테마 추가.
- **효과:** SNS 공유 시 “에덴 성경책으로 만든 카드” 인지도 상승.
- **구현:** `ShareVerseCard`에 테마 파라미터 추가, 설정에서 기본 테마 선택.

### ⑦ 짧은 묵상 가이드 (1문장)
- **내용:** 오늘의 말씀 또는 상담 응답 아래에 **한 문장 묵상 질문/초안** 제공 (예: “오늘 나에게 ‘목자’는 누구인가?”).
- **효과:** 읽기만이 아닌 묵상까지 연결되는 인상.
- **구현:** `counsel_presets` 또는 별도 JSON에 `meditationPrompt` 필드 추가, UI에 1문장 표시.

## 3. 눈·귀·이미지로 보는 성경책 (TypeCast 음원 + 미드저니 이미지)

**콘셉트:** 성경을 **눈으로 읽고** → **TypeCast로 생성한 고품질 음원으로 듣고** → **미드저니 스타일 이미지로 장면을 보는** 올인원 경험.

### ① 현재 상태
- **눈:** 성경 본문 읽기 ✅
- **귀:** 기기 기본 TTS (무료) ✅
- **음원/이미지:** 없음

### ② TypeCast 음원 탑재
- **의미:** 전문 성우 품질의 일관된 목소리로 장/권 단위 재생. TTS보다 몰입감·품질 우위.
- **구조 예시:** `assets/audio/` 에 책·장별 mp3 (예: `01_001.mp3` = 창세기 1장). 성경 읽기 화면 "들어보기" → 해당 장 재생. 재생 중 구절 하이라이트(선택) 가능.
- **고려:** **용량** — 1,189장 기준 수백 MB~수 GB. 앱 번들에는 핵심만(창세기·시편·요한복음 일부), 나머지는 **다운로드 팩** 또는 스트리밍 권장. **저작권** — TypeCast 생성 음원의 상업적 사용·재배포 허용 범위 확인 필수.
- **효과:** "프리미엄 낭독" 차별화, 통독·출퇴근 청취 경험.

### ③ 미드저니 스타일 이미지로 보는 성경
- **의미:** 구절/장면마다 AI 생성 이미지(미드저니 풍)를 붙여 **일러스트 성경책**처럼 제공.
- **구조 예시:** `assets/images/verse/` 에 구절/장 단위 이미지. 성경 읽기 "이미지로 보기" 토글이나 오늘의 말씀 카드 배경에만 적용해 분량 조절.
- **고려:** **Midjourney ToS** — 상업적 사용·앱 배포 허용 여부 최신 확인. **일관성** — 스타일 통일, 민감한 장면은 선별 구절만 이미지화. **용량** — 핵심만 포함 또는 저해상도·WebP.
- **효과:** 시각적 몰입, "보는 성경" 콘셉트, SNS 공유·청소년·시각형 사용자 확보.

### ④ 통합 UX 예시
- 읽기 화면: [텍스트] / [이미지 보기] 전환. 재생은 [TTS] / [TypeCast 음원] 선택.
- 오늘의 말씀: 카드 배경을 해당 구절용 이미지(저해상도)로.
- 말씀 상담: 응답 구절에 연결된 이미지 1장(있을 경우만).

### ⑤ 권장 진행 순서
1. **TypeCast·Midjourney 이용약관** 확인 후 상업·앱 탑재 가능 여부 정리.
2. **파일럿:** 창세기 1~3장 + 시편 23편만 TypeCast 음원 + 이미지 5~10장 제작 후 앱에 탑재, 반응 확인.
3. 용량·저작권 허용 시 장 단위 음원 인덱스(JSON)와 이미지 매핑(verse_id → asset) 설계.
4. 필요 시 "프리미엄" 또는 "다운로드 팩"으로 확장.
