# 에덴 성경책 — 릴리스 빌드 가이드

## 준비물 확인
- Flutter SDK 설치됨 (`flutter doctor` 통과)
- Android Studio 설치됨
- Java/JDK 17 설치됨
- Google Play Console 개발자 계정 (25달러 등록비)

---

## STEP 1. 키스토어 생성

터미널을 열고 아래 명령어를 **그대로** 복사-붙여넣기 하세요.

```bash
keytool -genkey -v \
  -keystore ~/eden-release.jks \
  -storetype JKS \
  -keyalg RSA \
  -keysize 2048 \
  -validity 10000 \
  -alias eden
```

실행하면 아래 질문이 나옵니다. 하나씩 입력하세요:

```
키 저장소 비밀번호 입력: _______ (6자 이상, 메모 필수!)
새 비밀번호 다시 입력: _______ (위와 동일)
이름과 성을 입력하십시오: Eden Bible
조직 단위 이름을 입력하십시오: Dev
조직 이름을 입력하십시오: Rock of Grace
구/군/시 이름을 입력하십시오: Seoul
시/도 이름을 입력하십시오: Seoul
이 조직의 두 자리 국가 코드를 입력하십시오: KR
~이(가) 맞습니까? [아니오]: Y
<eden>에 대한 키 비밀번호를 입력하십시오
    (키 저장소 비밀번호와 같은 경우 RETURN을 누르십시오): (엔터)
```

⚠️ 비밀번호를 반드시 메모하세요! 분실하면 앱 업데이트 불가합니다.

완료되면 `~/eden-release.jks` 파일이 생성됩니다.
확인: `ls -la ~/eden-release.jks`

## STEP 2. key.properties 파일 수정

아래 파일을 열어서 비밀번호를 입력하세요:

```bash
open /Users/pes/Desktop/Github/EdenBible/android/key.properties
```

또는 터미널에서:

```bash
nano /Users/pes/Desktop/Github/EdenBible/android/key.properties
```

파일 내용을 이렇게 수정하세요 (비밀번호를 실제값으로):

```properties
storePassword=내가_설정한_비밀번호
keyPassword=내가_설정한_비밀번호
keyAlias=eden
storeFile=/Users/pes/eden-release.jks
```

⚠️ 이 파일은 절대 GitHub에 올리면 안 됩니다! (.gitignore에 이미 추가됨)

## STEP 6. AAB (App Bundle) 빌드

```bash

```

```

```

⚠️ 에러가 나면?
- `Keystore was tampered with` → key.properties의 비밀번호 확인
- `No key with alias` → keyAlias가 "eden"인지 확인
- `Could not resolve` → `flutter clean && flutter pub get` 다시 실행

## STEP 8. Google Play Console 업로드

1. https://play.google.com/console 접속
2. "앱 만들기" 클릭
3. 앱 이름: "에덴 성경책"
4. 기본 언어: 한국어
5. 앱 유형: 앱
6. 무료/유료: 무료
7. "앱 만들기" 클릭

### 8-1. 앱 콘텐츠 설정 (Policy > App content)
- 개인정보처리방침 URL 입력 (GitHub Pages 등에 호스팅한 URL)
- 광고 포함: 아니오
- 앱 액세스: 모든 기능에 제한 없이 액세스 가능
- 콘텐츠 등급: 설문 작성 → 전체이용가
- 타겟 연령: 모든 연령
- 뉴스 앱: 아니오
- 코로나19: 아니오
- 데이터 보안: 데이터 수집 없음, 데이터 공유 없음

### 8-2. 스토어 등록정보
- 앱 이름: 에덴 성경책
- 짧은 설명: 오프라인 성경 읽기 + 감정별 맞춤 힐링 + 수면 묵상
- 긴 설명: (docs/11_스토어_리스팅_자료.md 참고, "AI" 표현 제거)
- 스크린샷 8장 업로드
- 피처 그래픽 (1024×500) 업로드
- 앱 아이콘 (512×512) 업로드

### 8-3. Closed Testing (필수!)
- 테스트 > Closed Testing > 트랙 만들기
- app-release.aab 업로드
- 테스터 12명 이메일 등록 (가족, 친구, 교회 지인)
- 테스터에게 옵트인 링크 공유
- 14일간 테스트 진행
- 14일 후 프로덕션 전환 신청

## 키스토어 백업 (매우 중요!)

키스토어 파일과 비밀번호를 안전한 곳에 백업하세요.
분실하면 앱 업데이트가 영원히 불가능합니다.

```bash
# 안전한 곳에 복사
cp ~/eden-release.jks ~/Google\ Drive/eden-backup/eden-release.jks
```

백업할 것:
1. ~/eden-release.jks (키스토어 파일)
2. 비밀번호 (메모장/비밀번호 관리자에 저장)
3. key.properties 파일 내용

## 문제 해결

### "Execution failed for task ':app:validateSigningRelease'"
→ key.properties의 storeFile 경로가 정확한지 확인

### "flutter build appbundle" 시 메모리 부족
→ `flutter build appbundle --release --no-tree-shake-icons`

### 빌드는 되는데 앱이 크래시
→ `flutter run --release` 로 실기기에서 먼저 테스트

### Play Console에서 "앱 서명 키 없음"
→ Play Console > 설정 > 앱 서명에서 "Google이 앱 서명 키 관리" 선택 (권장)
