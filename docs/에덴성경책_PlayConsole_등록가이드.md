```

2. PRIVACY_POLICY.md 파일 업로드

방법 B — Google Sites:
```
1. sites.google.com 접속

### 2-7. 데이터 보안

이것이 가장 중요합니다. 아래처럼 작성하세요.

| 질문 | 답변 |
|------|------|

에덴 성경책은 **서버에 어떤 데이터도 전송하지 않으므로** 모든 항목을 "수집/공유 없음"으로 선택합니다.

## STEP 4. 테스트 트랙 설정 (Closed Testing)

⚠️ **2026년 현재 신규 개인 개발자는 Closed Testing 필수!**
바로 프로덕션 출시가 불가능합니다.

### 4-1. 테스트 트랙 만들기

왼쪽 메뉴 **"테스트 > Closed testing"** → **"새 트랙 만들기"**

| 항목 | 입력값 |
|------|--------|
| 트랙 이름 | `Closed testing` (기본값) |

### 4-2. AAB 업로드

**"새 버전 만들기"** 클릭 → **app-release.aab** 파일 업로드

AAB 파일 위치:
```
/Users/pes/Desktop/Github/EdenBible/build/app/outputs/bundle/release/app-release.aab
```

업로드 후:
| 항목 | 입력값 |
|------|--------|
| 버전 이름 | `1.0.0` (자동 입력됨) |
| 출시 노트 | `에덴 성경책 첫 번째 버전입니다.` |

### 4-3. 테스터 등록

**"테스터 관리"** → **"이메일 목록 만들기"**

| 항목 | 입력값 |
|------|--------|
| 목록 이름 | `에덴 테스터` |
| 이메일 추가 | 12명 이상의 Gmail 주소 입력 |

**테스터 확보 방법:**
- 가족 Gmail 주소
- 교회 지인/친구
- 직장 동료
- 본인 서브 계정

### 4-4. 테스터에게 링크 공유

Closed testing 트랙을 저장하면 **옵트인 URL**이 생성됩니다.

```
https://play.google.com/apps/testing/com.edenbible.app
```

이 링크를 테스터 12명에게 카카오톡/문자로 보내서:
1. 링크 클릭 → "테스터로 참여" 수락
2. Play 스토어에서 앱 설치
3. 14일간 사용

### 4-5. 14일 대기

**Closed Testing 14일 후** → 프로덕션 전환 신청 가능

## ⚠️ 주의사항

1. **"AI" 표현 절대 사용 금지** — 긴 설명, 짧은 설명 어디에도 "AI" 단어가 없어야 합니다
2. **스크린샷은 실제 앱 화면** — 목업이나 합성 이미지 사용 시 거절 가능
3. **개인정보처리방침 URL이 반드시 접근 가능해야 함** — 404 에러 나면 즉시 거절
4. **패키지명 com.edenbible.app 확인** — com.example이면 즉시 거절
5. **앱이 크래시 없이 실행되어야 함** — 심사 중 크래시 1회만 나도 거절
6. **14일 Closed Testing은 건너뛸 수 없음** — 신규 개인 개발자 필수 요구사항
