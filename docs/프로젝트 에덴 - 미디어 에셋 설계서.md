# 프로젝트 에덴 — 미디어 에셋(음원·이미지) 기술 설계서

**문서 버전:** v1.0  
**작성일:** 2026-03-19  
**목적:** 성경 66권 전체에 대한 TypeCast 음원 + Midjourney 이미지를 앱에 탑재하되, 용량 문제를 해결하기 위한 아키텍처 설계

---

## 1. 용량 추정 — 왜 설계가 필요한가

### 1-1. 성경 구조 기본 수치

| 항목 | 수치 |
|------|------|
| 성경 전체 권 수 | 66권 |
| 성경 전체 장 수 | 1,189장 |
| 성경 전체 절 수 | 31,102절 |
| 평균 1장 읽기 시간 | 약 3~5분 (한국어 TTS 기준) |

### 1-2. 음원 (TypeCast) 용량 추정

| 음질 | 비트레이트 | 1장 평균 (4분) | 1,189장 전체 | 비고 |
|------|-----------|---------------|-------------|------|
| 고음질 MP3 | 192kbps | ~5.7MB | **~6.8GB** | 원본 보존 품질 |
| 표준 MP3 | 128kbps | ~3.8MB | **~4.5GB** | 충분히 깨끗 |
| 압축 MP3 | 64kbps | ~1.9MB | **~2.3GB** | 음성만이면 충분 |
| Opus (권장) | 48kbps | ~1.4MB | **~1.7GB** | 최신 코덱, 최고 효율 |
| AAC-HE v2 | 32kbps | ~0.96MB | **~1.1GB** | iOS 최적화 |

> **결론:** 가장 효율적인 코덱(Opus 48kbps)을 써도 전체 성경 음원은 **~1.7GB**. 앱 번들에 전부 넣으면 구글 플레이 150MB 제한을 훨씬 초과.

### 1-3. 이미지 (Midjourney) 용량 추정

| 적용 단위 | 이미지 수 | WebP (100KB 기준) | WebP (50KB 기준) | 비고 |
|-----------|----------|------------------|-----------------|------|
| 장(chapter)마다 1장 | 1,189장 | **~119MB** | **~59MB** | 장면 대표 이미지 |
| 구절(verse)마다 1장 | 31,102장 | **~3.1GB** | **~1.6GB** | 비현실적 |
| 주요 장면만 (10%) | ~120장 | **~12MB** | **~6MB** | 가장 현실적 |
| 책(book)마다 1장 | 66장 | **~6.6MB** | **~3.3MB** | 최소 단위 |

> **결론:** 장 단위는 ~60~120MB, 절 단위는 수 GB로 비현실적. **장 단위 + 선별적 절 단위**가 최적.

### 1-4. 총 합산 시나리오

| 시나리오 | 음원 | 이미지 | 합계 | 앱 번들 가능? |
|---------|------|--------|------|-------------|
| A. 전부 번들 (고음질) | 4.5GB | 119MB | **~4.6GB** | ❌ 불가능 |
| B. 전부 번들 (최소) | 1.1GB | 59MB | **~1.2GB** | ❌ 불가능 |
| C. 핵심만 번들 + 나머지 다운로드 | 50MB | 10MB | **~60MB** | ✅ 가능 |
| D. 음원 0 + 이미지만 번들 | 0 | 59MB | **~59MB** | ✅ 가능 |

> **채택: 시나리오 C** — 핵심 에셋만 앱에 포함, 나머지는 사용자 선택 다운로드

## 2. 3-Tier 에셋 전달 아키텍처

앱 용량 문제를 해결하기 위해 에셋을 3개 계층으로 나눕니다.

```
┌─────────────────────────────────────────────────────────────┐
│                        Tier 1: 번들                          │
│  앱 설치 시 포함 (50~80MB)                                    │
│  • 핵심 5개 책 음원 (창세기, 시편, 잠언, 이사야, 요한복음)        │
│  • 오늘의 말씀 30개 구절 이미지                                 │
│  • 책(book)별 대표 이미지 66장                                 │
│  • 공유카드 배경 10종                                          │
├─────────────────────────────────────────────────────────────┤
│                     Tier 2: 다운로드 팩                        │
│  사용자가 Wi-Fi에서 선택 다운로드                                │
│  • 9개 팩으로 분할 (모세오경, 역사서, 시가서, ...)               │
│  • 팩당 100~250MB (음원+이미지)                                │
│  • 전체 다운로드 시 ~1.5GB                                     │
├─────────────────────────────────────────────────────────────┤
│                     Tier 3: 스트리밍                           │
│  다운로드 없이 실시간 재생 (프리미엄 기능)                        │
│  • CDN에서 장 단위로 스트리밍                                   │
│  • 캐시: 최근 재생 20장 자동 보관                                │
│  • 네트워크 없으면 Tier 1/2 fallback → 기기 TTS               │
└─────────────────────────────────────────────────────────────┘
```

### 2-1. Tier 1: 번들 에셋 (앱 설치 시 포함)

**목표:** 설치 즉시 핵심 기능 체험 가능. 앱 크기 80MB 이내 유지.

**포함 음원 (약 40MB):**

| 책 | 장 수 | 추정 용량 (Opus 48k) | 선정 이유 |
|----|------|---------------------|----------|
| 창세기 1~3장 | 3 | ~4MB | 성경 시작, 천지창조 |
| 시편 23, 91, 121편 | 3 | ~3MB | 가장 유명한 시편 |
| 잠언 3장 | 1 | ~1.5MB | 유명 잠언 |
| 이사야 40장 | 1 | ~2MB | 위로 대표 구절 |
| 마태복음 5~7장 | 3 | ~6MB | 산상수훈 |
| 요한복음 1, 3, 14장 | 3 | ~5MB | 복음 핵심 |
| 고린도전서 13장 | 1 | ~1.5MB | 사랑장 |
| 빌립보서 4장 | 1 | ~1.5MB | 기쁨장 |
| 요한계시록 21~22장 | 2 | ~3MB | 성경 마지막 |
| **합계** | **~18장** | **~28MB** | |

**포함 이미지 (약 15MB):**

| 종류 | 수량 | 해상도 | 포맷 | 추정 용량 |
|------|------|--------|------|----------|
| 책 대표 이미지 | 66장 | 480x640 | WebP q75 | ~3.3MB (50KB/장) |
| 오늘의 말씀 배경 | 30장 | 720x960 | WebP q80 | ~6MB (200KB/장) |
| 공유카드 배경 | 10장 | 1080x1350 | WebP q85 | ~4MB (400KB/장) |
| **합계** | **106장** | | | **~13MB** |

### 2-2. Tier 2: 다운로드 팩 설계

성경을 카테고리별 **9개 팩**으로 분할합니다.

| 팩 ID | 팩 이름 | 포함 책 | 장 수 | 음원 추정 | 이미지 추정 | 합계 |
|-------|---------|--------|------|----------|-----------|------|
| pack_01 | 모세오경 | 창~신 (1~5) | 187 | ~262MB | ~9MB | **~271MB** |
| pack_02 | 역사서 (상) | 수~삼하 (6~10) | 107 | ~150MB | ~5MB | **~155MB** |
| pack_03 | 역사서 (하) | 왕상~에 (11~17) | 130 | ~182MB | ~7MB | **~189MB** |
| pack_04 | 시가서 | 욥~아 (18~22) | 222 | ~311MB | ~11MB | **~322MB** |
| pack_05 | 대선지서 | 사~단 (23~27) | 183 | ~256MB | ~9MB | **~265MB** |
| pack_06 | 소선지서 | 호~말 (28~39) | 67 | ~94MB | ~3MB | **~97MB** |
| pack_07 | 복음서 | 마~요 (40~43) | 89 | ~125MB | ~4MB | **~129MB** |
| pack_08 | 사도행전~서신 | 행~몬 (44~57) | 128 | ~179MB | ~6MB | **~185MB** |
| pack_09 | 일반서신~요한계시록 | 히~계 (58~66) | 76 | ~106MB | ~4MB | **~110MB** |
| | **합계** | **66권** | **1,189** | **~1,665MB** | **~58MB** | **~1,723MB** |

> **팩당 평균 ~190MB**, 가장 큰 팩(시가서)이 ~322MB로 Wi-Fi 다운로드에 적합한 범위.

### 2-3. Tier 3: 스트리밍 (선택적 프리미엄)

**동작 방식:**
1. 사용자가 다운로드하지 않은 장을 재생하면 CDN에서 스트리밍
2. 스트리밍 중 자동으로 로컬에 캐시 (최근 20장)
3. 캐시 용량 상한 100MB, LRU(Least Recently Used) 정책으로 자동 정리
4. 네트워크 없으면: 다운로드된 팩 → 번들 → 기기 TTS 순서로 fallback

**CDN 구조 (예시: Firebase Storage / Cloudflare R2):**
```
cdn.eden-bible.app/
├── audio/
│   ├── ko/opus/          # 한국어 Opus 48kbps
│   │   ├── 01_001.opus   # 창세기 1장
│   │   ├── 01_002.opus
│   │   └── ...
│   └── ko/mp3/           # MP3 fallback (iOS 호환)
│       └── ...
└── images/
    ├── chapters/          # 장 대표 이미지
    │   ├── 01_001.webp
    │   └── ...
    └── verses/            # 주요 구절 이미지
        ├── 01_001_001.webp  # 창세기 1:1
        └── ...
```

## 5. 에셋 해소(Resolution) 서비스 설계

음원이나 이미지를 요청하면, 가용한 소스 중 최적을 자동 선택하는 서비스입니다.

### 5-1. 해소 우선순위 (Fallback Chain)

```
음원 재생 요청: playAudio(bookId: 1, chapter: 4)

┌──────────────────────────────────────────────────┐
│  1. 번들 확인                                       │
│     assets/audio/bundled/01_004.opus 존재?          │
│     → YES: 재생 ✅                                  │
│     → NO: 다음 단계                                  │
├──────────────────────────────────────────────────┤
│  2. 다운로드 팩 확인                                  │
│     files/packs/pack_01/audio/01_004.opus 존재?     │
│     → YES: 재생 ✅                                  │
│     → NO: 다음 단계                                  │
├──────────────────────────────────────────────────┤
│  3. 스트리밍 캐시 확인                                │
│     files/cache/audio/01_004.opus 존재?             │
│     → YES: 재생 ✅                                  │
│     → NO: 다음 단계                                  │
├──────────────────────────────────────────────────┤
│  4. 네트워크 스트리밍                                 │
│     네트워크 가용? → CDN에서 스트리밍 + 캐시 저장 ✅    │
│     → 네트워크 없음: 다음 단계                         │
├──────────────────────────────────────────────────┤
│  5. Fallback: 기기 TTS                              │
│     flutter_tts로 텍스트 읽기 ✅                     │
│     (항상 동작, 오프라인 보장)                          │
└──────────────────────────────────────────────────┘
```

### 5-2. Dart 서비스 인터페이스

```dart
/// 미디어 에셋 해소 서비스
class MediaAssetService {
  // ─── 음원 ───
  
  /// 음원 소스를 해소하여 재생 가능한 URI 반환
  Future<AudioSource> resolveAudio(int bookId, int chapter);
  
  /// 현재 장의 음원 가용 여부와 소스 타입
  AudioAvailability getAudioAvailability(int bookId, int chapter);
  
  // ─── 이미지 ───
  
  /// 책 대표 이미지 (항상 번들에 존재)
  ImageProvider getBookCover(int bookId);
  
  /// 장 장면 이미지 (번들/팩/캐시/네트워크)

enum AudioSourceType {
```

## 9. 오디오 플레이어 서비스 확장 설계

기존 `TtsService`를 확장하여 TypeCast 음원 재생을 통합합니다.

### 9-1. 통합 오디오 서비스 구조

```dart
/// 통합 오디오 재생 서비스 (TTS + TypeCast 음원)
class AudioPlayerService extends ChangeNotifier {
  
  // ─── 재생 상태 ───
  AudioPlayMode _mode = AudioPlayMode.idle;     // idle / tts / typecast
  AudioSourceType _sourceType = AudioSourceType.tts;
  bool _isPlaying = false;
  Duration _position = Duration.zero;
  Duration _duration = Duration.zero;
  int _currentHighlightVerse = 0;               // 현재 하이라이트 구절
  
  // ─── 재생 제어 ───
  
  /// 장 전체 재생 (자동으로 최적 소스 선택)
  Future<void> playChapter(int bookId, int chapter) async {
    final source = await MediaAssetService().resolveAudio(bookId, chapter);
    
    if (source.type == AudioSourceType.tts) {
      // 기존 TTS 방식
      await _playWithTts(bookId, chapter);
    } else {
      // TypeCast 음원 재생
      await _playAudioFile(source);
      // 싱크 데이터가 있으면 구절 하이라이트 시작
      _startVerseSync(bookId, chapter);
    }
  }
  
  /// 재생/일시정지 토글
  Future<void> togglePlayPause();
  
  /// 탐색 (seek)
  Future<void> seekTo(Duration position);
  
  /// 다음 장 자동 재생
  Future<void> playNextChapter();
  
  /// 속도 조절 (0.5x ~ 2.0x)
  Future<void> setSpeed(double speed);
  
  /// 수면 타이머 (30분, 1시간, 장 끝까지)
  void setSleepTimer(SleepTimerMode mode);
  
  // ─── 구절 싱크 ───
  
  /// 현재 재생 위치에 해당하는 구절 번호
  int get currentVerse => _currentHighlightVerse;
  
  /// 구절 싱크 콜백 (UI에서 하이라이트용)
  Stream<int> get verseHighlightStream;
}

enum AudioPlayMode { idle, tts, typecast }

enum SleepTimerMode { off, minutes30, hour1, endOfChapter }
```
