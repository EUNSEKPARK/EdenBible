**문서 버전:** v1.0  
**작성일:** 2026-03-19  
**목적:** 읽는 성경 / 듣는 성경 / 보는 성경 3단계 모드 구성과, "보는 성경"의 넷플릭스 자막 스타일 UI 설계

## 1. 3단계 성경 모드 개요

사용자 경험과 수익 모델을 연결하는 핵심 구조입니다. 아래에서 위로 갈수록 몰입도가 높아지고, 프리미엄 가치가 올라갑니다.

```
┌───────────────────────────────────────────────────────┐
│                                                        │
│    ✨ 보는 성경 (Visual Bible)          [프리미엄+]    │
│    ─────────────────────────────────                   │
│    기본 텍스트 + TypeCast 음성 + Midjourney 이미지      │
│    이미지가 메인, 성경 구절은 넷플릭스 자막처럼 표시     │
│    → "영화처럼 성경을 본다"                             │
│                                                        │
├───────────────────────────────────────────────────────┤
│                                                        │
│    🎧 듣는 성경 (Audio Bible)           [프리미엄]     │
│    ─────────────────────────────────                   │
│    기본 텍스트 + TypeCast 전문 성우 음성                │
│    재생 중 구절 자동 하이라이트 (싱크)                  │
│    → "성우가 읽어주는 오디오북"                         │
│                                                        │
├───────────────────────────────────────────────────────┤
│                                                        │
│    📖 읽는 성경 (Text Bible)            [무료]         │
│    ─────────────────────────────────                   │
│    기본 텍스트 + 기기 TTS (무료)                        │
│    개역한글 / KJV 번역본 전환                           │
│    → 현재 구현된 기본 모드                              │
│                                                        │
└───────────────────────────────────────────────────────┘
```

### 1-1. 모드별 기능 매트릭스

| 기능 | 📖 읽는 성경 | 🎧 듣는 성경 | ✨ 보는 성경 |
|------|:----------:|:----------:|:----------:|
| 성경 텍스트 표시 | ✅ 전체 | ✅ 전체 | ✅ 자막 형태 |
| 개역한글 / KJV 전환 | ✅ | ✅ | ✅ |
| 북마크 / 하이라이트 | ✅ | ✅ | ✅ |
| 검색 | ✅ | ✅ | ✅ |
| 기기 TTS (무료) | ✅ | ❌ (TypeCast 대체) | ❌ |
| TypeCast 전문 음성 | ❌ | ✅ | ✅ |
| 구절 싱크 하이라이트 | ❌ | ✅ | ✅ |
| 재생 속도 조절 | ❌ | ✅ (0.5x~2.0x) | ✅ |
| 수면 타이머 | ❌ | ✅ | ✅ |
| Midjourney 배경 이미지 | ❌ | ❌ | ✅ (전체화면) |
| 자막 스타일 선택 | ❌ | ❌ | ✅ (5종) |
| 이미지 전환 애니메이션 | ❌ | ❌ | ✅ |
| 자막 위치/크기 조절 | ❌ | ❌ | ✅ |
| **가격** | **무료** | **프리미엄** | **프리미엄+** |

### 1-2. 모드 전환 UX

성경 읽기 화면의 상단에 모드 전환 토글을 배치합니다.

```
┌─────────────────────────────────────┐
│  [📖 읽기]  [🎧 듣기]  [✨ 보기]   │
│     ───      ───       ━━━         │
│                        (활성)       │
└─────────────────────────────────────┘

미잠금 모드: 일반 탭 버튼
잠금 모드:  자물쇠 아이콘 + 탭 시 프리미엄 안내 시트
```

**전환 동작:**
- 읽기 → 듣기: 텍스트는 그대로, 하단 플레이어 바가 TypeCast 플레이어로 변경
- 듣기 → 보기: 화면이 전체화면 이미지로 전환되며 텍스트가 자막으로 변환
- 보기 → 읽기: 이미지 페이드아웃, 일반 텍스트 뷰로 복귀

## 2. 보는 성경 — 화면 구성

### 2-1. 전체 레이아웃

```
┌──────────────────────────────────┐
│ ← 창세기 1장          [📖][🎧][✨]│  ← 상단 바 (반투명, 탭 시 표시/숨김)
│                                   │
│                                   │
│                                   │
│        [전체화면 이미지]            │  ← Midjourney 이미지 (장면별)
│        크로스페이드 전환             │
│                                   │
│                                   │
│                                   │
│                                   │
│      ┌─────────────────────┐      │
│      │   창세기 1:1         │      │  ← 절 참조 (작은 Gold 텍스트)
│      │                     │      │
│      │  태초에 하나님이      │      │  ← 넷플릭스 스타일 자막
│      │  천지를 창조하시니라  │      │
│      └─────────────────────┘      │
│                                   │
│  ◁  ▶  ▷    ━━━━━━━━░░░  1:15    │  ← 하단 컨트롤 바 (반투명)
└──────────────────────────────────┘
```

### 2-2. 계층 구조 (Z-index)

```
최하층   z-0   Midjourney 이미지 (전체화면)
         z-1   이미지 전환 오버레이 (크로스페이드용)
         z-2   상단 그라디언트 (네비게이션 가독성)
         z-3   하단 그라디언트 (컨트롤 바 가독성)
         z-4   자막 영역
         z-5   상단 네비게이션 바
최상층   z-6   하단 오디오 컨트롤 바
```

### 2-3. 자동 숨김 (Auto-hide)

넷플릭스처럼, 재생 중에는 UI를 숨기고 이미지 + 자막만 표시합니다.

| 요소 | 재생 중 | 일시정지 | 탭(터치) 시 |
|------|--------|--------|-----------|
| 상단 바 | 숨김 | 표시 | 3초간 표시 후 다시 숨김 |
| 하단 컨트롤 | 숨김 | 표시 | 3초간 표시 후 다시 숨김 |
| 자막 | **항상 표시** | 항상 표시 | 항상 표시 |
| 이미지 | 항상 표시 | 항상 표시 | 항상 표시 |

## 3. 넷플릭스 자막 스타일 시스템

### 3-1. 자막 스타일 5종

사용자가 설정에서 선택할 수 있는 5가지 자막 스타일입니다.

#### Style A: Netflix Classic (기본값, 권장)

넷플릭스 기본 자막과 동일한 스타일. 가독성 최우선.

```
배경:   rgba(0, 0, 0, 0.75)
텍스트: #FFFFFF (순백)
폰트:   Pretendard 또는 시스템 기본
크기:   17px (기본, 사용자 조절 가능 14~24px)
행간:   1.7
패딩:   8px 18px
정렬:   중앙 정렬
모서리: 4px (넷플릭스는 거의 직각)
위치:   화면 하단에서 10% 위
최대폭: 화면 너비의 85%
```

**Flutter 구현:**
```dart
Container(
  padding: const EdgeInsets.symmetric(horizontal: 18, vertical: 8),
  decoration: BoxDecoration(
    color: Colors.black.withOpacity(0.75),
    borderRadius: BorderRadius.circular(4),
  ),
  child: Text(
    verseText,
    textAlign: TextAlign.center,
    style: TextStyle(
      fontSize: settings.subtitleFontSize,  // 기본 17
      color: Colors.white,
      height: 1.7,
      fontWeight: FontWeight.w400,
      letterSpacing: 0.3,
    ),
  ),
)
```

#### Style B: Glass Blur

Apple 스타일의 유리 느낌. 배경 이미지가 은은하게 비침.

```
배경:   rgba(0, 0, 0, 0.30)
블러:   backdrop-filter: blur(12px)
테두리: 0.5px solid rgba(255, 255, 255, 0.08)
텍스트: rgba(255, 255, 255, 0.95)
모서리: 16px
패딩:   12px 22px
```

**Flutter 구현:**
```dart
ClipRRect(
  borderRadius: BorderRadius.circular(16),
  child: BackdropFilter(
    filter: ImageFilter.blur(sigmaX: 12, sigmaY: 12),
    child: Container(
      padding: const EdgeInsets.symmetric(horizontal: 22, vertical: 12),
      decoration: BoxDecoration(
        color: Colors.black.withOpacity(0.30),
        borderRadius: BorderRadius.circular(16),
        border: Border.all(color: Colors.white.withOpacity(0.08)),
      ),
      child: Text(verseText, ...),
    ),
  ),
)
```

#### Style C: Minimal

배경 없이 텍스트 쉐도우만으로 가독성 확보. 이미지가 가장 잘 보임.

```
배경:   없음
텍스트: #FFFFFF
쉐도우: 0 2px 12px rgba(0,0,0,0.9), 0 0 40px rgba(0,0,0,0.6)
크기:   18px (약간 크게)
굵기:   w500 (약간 굵게)
```

> ⚠ 밝은 이미지에서는 가독성이 떨어질 수 있음. 고급 사용자용.

#### Style D: Cinematic Bar

영화 자막 느낌. 왼쪽에 에덴 Gold 액센트 라인.

```
배경:   rgba(0, 0, 0, 0.85)
왼쪽:   3px solid #C9A96E (Warm Gold 액센트)
텍스트: rgba(255, 255, 255, 0.95)
스타일: italic
패딩:   10px 24px
모서리: 0px (직각)
```

#### Style E: Karaoke Highlight

현재 재생 중인 구절이 Gold로 강조되고, 아직 읽지 않은 부분은 흐리게 표시.

```
배경:        rgba(0, 0, 0, 0.70)
현재 구절:   #C9A96E (Warm Gold), fontWeight: w500
이전 구절:   rgba(255, 255, 255, 0.35)
다음 구절:   rgba(255, 255, 255, 0.45)
모서리:      6px
```

> TypeCast 구절 싱크 데이터와 연동하여 실시간 하이라이트 가능.

### 3-2. 넷플릭스 자막 핵심 설계 원칙

넷플릭스의 Timed Text Style Guide에서 차용한 원칙들:

| 원칙 | 넷플릭스 기준 | 에덴 적용 |
|------|-------------|----------|
| **최대 줄 수** | 2줄 | 2~3줄 (성경 구절은 약간 길 수 있음) |
| **1줄 최대 글자 수** | 42자 (한국어) | 40자 (여유 있게) |
| **표시 시간** | 최소 1초, 최대 7초 | 구절 길이에 비례 (TypeCast 싱크) |
| **위치** | 하단 10% | 하단 10% (기본, 조절 가능) |
| **배경** | 검정 75% | 검정 75% (기본 스타일) |
| **폰트 크기** | 디스플레이 대비 적정 | 기본 17px, 14~24px 조절 가능 |
| **줄 간격** | 1.5~1.8 | 1.7 |
| **줄바꿈** | 의미 단위로 끊기 | 절 내 의미 단위로 자동 분리 |
| **전환** | 페이드인/아웃 | 0.3초 페이드 전환 |

### 3-3. 자막 줄바꿈 알고리즘

성경 구절을 자막으로 표시할 때, 의미 단위로 줄을 끊어야 자연스럽습니다.

**규칙:**
1. 1줄 최대 20자 (한국어 기준, 모바일 화면 폭 고려)
2. 조사 뒤에서 끊지 않음 (예: "하나님이" 한 단어로 유지)
3. 쉼표, 마침표 뒤에서 우선 끊기
4. "~하시니라", "~하였더라" 등 종결어미는 앞 내용과 같은 줄
5. 3줄을 초과하면 2개 자막으로 분할 (순차 표시)

**예시:**
```
원문: "태초에 하나님이 천지를 창조하시니라"
자막: 태초에 하나님이
      천지를 창조하시니라

원문: "땅이 혼돈하고 공허하며 흑암이 깊음 위에 있고 하나님의 영은 수면 위에 운행하시니라"
자막 1: 땅이 혼돈하고 공허하며
        흑암이 깊음 위에 있고
자막 2: 하나님의 영은
        수면 위에 운행하시니라
```

**Dart 구현 (간이 알고리즘):**
```dart
List<String> splitVerseToSubtitles(String text, {int maxCharsPerLine = 20, int maxLines = 2}) {
  // 쉼표/마침표 기준 1차 분리
  final segments = text.split(RegExp(r'(?<=[,.])\s*'));
  
  final subtitles = <String>[];
  var currentLines = <String>[];
  var currentLine = '';
  
  for (final segment in segments) {
    final words = segment.split(' ');
    for (final word in words) {
      if ((currentLine + ' ' + word).trim().length > maxCharsPerLine && currentLine.isNotEmpty) {
        currentLines.add(currentLine.trim());
        currentLine = word;
        
        if (currentLines.length >= maxLines) {
          subtitles.add(currentLines.join('\n'));
          currentLines = [];
        }
      } else {
        currentLine = (currentLine + ' ' + word).trim();
      }
    }
  }
  
  if (currentLine.isNotEmpty) currentLines.add(currentLine.trim());
  if (currentLines.isNotEmpty) subtitles.add(currentLines.join('\n'));
  
  return subtitles;
}
```

## 4. 이미지 전환 시스템

### 4-1. 이미지 전환 타이밍

| 전환 기준 | 설명 | 장점 |
|----------|------|------|
| **절(verse) 단위** | 매 절마다 이미지 변경 | 가장 역동적, 이미지 많이 필요 |
| **의미 단락 단위** (권장) | 3~5절마다 변경 | 자연스러움, 적정 이미지 수 |
| **장(chapter) 단위** | 장 전체 1개 이미지 | 이미지 적게 필요, 단조로울 수 있음 |

> 권장: **의미 단락 단위**를 기본으로, 절 단위 매핑 데이터가 없으면 장 단위로 fallback.

### 4-2. 크로스페이드 애니메이션

이미지 전환 시 부드러운 크로스페이드(교차 용해)를 사용합니다.

```dart
// 두 개의 이미지 레이어를 겹쳐서 크로스페이드
Stack(
  children: [
    // 이전 이미지 (fade out)
    AnimatedOpacity(
      opacity: _showingFirst ? 1.0 : 0.0,
      duration: const Duration(milliseconds: 1500),
      child: Image.asset(_currentImage, fit: BoxFit.cover),
    ),
    // 다음 이미지 (fade in)
    AnimatedOpacity(
      opacity: _showingFirst ? 0.0 : 1.0,
      duration: const Duration(milliseconds: 1500),
      child: Image.asset(_nextImage, fit: BoxFit.cover),
    ),
  ],
)
```

### 4-3. Ken Burns 효과 (선택적)

이미지가 정적이면 지루할 수 있으므로, 넷플릭스 다큐멘터리 스타일의 느린 줌/패닝 효과를 적용합니다.

```dart
// 15초에 걸쳐 1.0 → 1.08 줌 + 약간의 패닝
AnimatedContainer(
  duration: const Duration(seconds: 15),
  transform: Matrix4.identity()
    ..scale(_isZoomingIn ? 1.08 : 1.0)
    ..translate(_panX, _panY),
  child: Image.asset(imagePath, fit: BoxFit.cover),
)
```

## 6. 자막 사용자 설정

### 6-1. 설정 항목

설정 → 보는 성경 → 자막 설정에서 조절 가능한 항목:

| 설정 | 기본값 | 범위 | 설명 |
|------|-------|------|------|
| 자막 스타일 | Netflix Classic | 5종 선택 | 배경/투명도/모서리 스타일 |

| 자막 위치 | 하단 | 상단 / 중앙 / 하단 | 자막 표시 위치 |

| 전환 효과 | 크로스페이드 | 크로스페이드 / 컷 / 슬라이드 | 이미지 전환 방식 |
| Ken Burns 효과 | ON | ON / OFF | 느린 줌/패닝 효과 |
| 자동 다음 장 | ON | ON / OFF | 장 끝나면 다음 장 자동 재생 |

### 7-2. 이미지 없는 장의 fallback

모든 장에 장면별 이미지가 없을 수 있으므로, fallback 체계를 둡니다.


## 8. 모드 전환 애니메이션

### 8-1. 읽기 → 보기 전환

```

800ms   첫 번째 자막이 하단에서 페이드인
```

```
0ms     자막 페이드아웃

600ms   상단/하단 바가 읽기 모드로 복귀
800ms   전환 완료, 현재 재생 중이던 절 위치로 스크롤
```

## 9. 성능 고려사항

### 9-1. 이미지 프리로딩

현재 장면 이미지 외에 다음 2개 장면 이미지를 미리 로드합니다.

```dart
// 프리로딩 전략
void _preloadImages(int currentSceneIndex) {
  // 다음 2개 장면 이미지를 캐시에 미리 로드
  for (int i = 1; i <= 2; i++) {
    final nextIndex = currentSceneIndex + i;
    if (nextIndex < scenes.length) {
      precacheImage(
        AssetImage(scenes[nextIndex].imagePath),
        context,
      );
    }
  }
}
```

### 9-2. 메모리 관리

전체화면 이미지는 메모리를 많이 사용하므로:

| 전략 | 설명 |
|------|------|
| 최대 3장 캐시 | 현재 + 이전 + 다음 이미지만 메모리에 유지 |
| 해상도 제한 | 디바이스 화면 크기에 맞는 해상도만 로드 |
| 지연 해제 | 3장면 이전의 이미지는 메모리에서 해제 |

### 9-3. 배터리 최적화

보는 성경은 화면이 항상 켜져 있으므로:

```dart
// 보는 성경 모드 진입 시
WakelockPlus.enable();  // 화면 꺼짐 방지

// 수면 타이머 설정 시 해당 시간 후 해제
Future.delayed(sleepDuration, () {
  WakelockPlus.disable();
  _pausePlayback();
});
```

## 10. 수익 모델 연동

### 10-1. 티어별 접근 제어

```dart
enum BibleMode { reading, listening, visual }

bool canAccessMode(BibleMode mode, UserPlan plan) {
  switch (mode) {
    case BibleMode.reading:
      return true;  // 항상 무료
```
