## TC-01. 앱 시작 및 스플래시

| 항목 | 내용 |
|------|------|
| **기능 ID** | TC-01 |
| **화면** | 스플래시 화면 |
| **설명** | 앱 최초 실행 시 성경 데이터와 AI 상담 프리셋을 로드하고 메인 화면으로 전환 |

### 테스트 절차

| # | 테스트 항목 | 기대 결과 | 결과 |
|---|-----------|----------|------|
| 1-1 | 앱을 실행한다 | "Eden" 로고와 "Project Eden" 텍스트가 표시된다 | ☐ |
| 1-2 | 로딩 중 상태를 확인한다 | 로딩 스피너와 "성경 66권을 불러오는 중..." → "AI 상담 데이터를 준비하는 중..." 메시지가 순차 표시된다 | ☐ |
| 1-3 | 로딩이 완료되면 | 자동으로 메인 홈 화면(The Sanctuary)으로 전환된다 | ☐ |
| 1-4 | 앱을 종료 후 재실행한다 | 동일하게 스플래시 후 홈 화면이 표시된다 | ☐ |

## TC-02. 메인 홈 화면 (The Sanctuary)

| 항목 | 내용 |
|------|------|
| **기능 ID** | TC-02 |
| **화면** | HomeView |
| **설명** | 오늘의 말씀, 메뉴, 읽기 진행률, 최근 읽은 말씀 표시 |

### 테스트 절차

| # | 테스트 항목 | 기대 결과 | 결과 |
|---|-----------|----------|------|
| 2-1 | 홈 화면의 "오늘의 말씀" 카드를 확인한다 | 성경 구절 텍스트와 참조(예: "시편 23:1 • 개역한글")가 표시된다 | ☐ |
| 2-2 | 다음 날 앱을 실행한다 | 오늘의 말씀 구절이 변경된다 (날짜 기반 30개 구절 로테이션) | ☐ |
| 2-3 | 같은 날 여러 번 실행한다 | 같은 구절이 유지된다 | ☐ |
| 2-4 | 4개 아이콘 메뉴(성경 읽기, AI 상담, 성경 연구, 필사)를 확인한다 | 4개 메뉴가 2x2 그리드로 표시된다 | ☐ |
| 2-5 | "성경 읽기" 아이콘을 탭한다 | 하단 네비게이션이 "성경" 탭으로 전환되고 BibleView가 표시된다 | ☐ |
| 2-6 | "AI 상담" 아이콘을 탭한다 | 하단 네비게이션이 "상담" 탭으로 전환되고 CounselView가 표시된다 | ☐ |
| 2-7 | "읽기 여정" 카드를 확인한다 | 진행률 퍼센트와 프로그레스 바가 표시된다 | ☐ |
| 2-8 | "최근 읽은 말씀" 카드를 확인한다 | 마지막으로 읽은 책/장과 첫 구절이 표시된다 | ☐ |

## TC-03. 성경 읽기 (Scripture Reader)

| 항목 | 내용 |
|------|------|
| **기능 ID** | TC-03 |
| **화면** | BibleView |
| **설명** | 성경 66권 전체 읽기, 책/장 선택, 번역본 전환, 북마크 |

### 테스트 절차 — 기본 읽기

| # | 테스트 항목 | 기대 결과 | 결과 |
|---|-----------|----------|------|
| 3-1 | 성경 탭으로 이동한다 | 기본으로 창세기 1장이 표시된다 (최초 실행 시) | ☐ |
| 3-2 | 본문의 절 번호를 확인한다 | 각 절 왼쪽에 절 번호가 작은 글씨로 표시된다 | ☐ |
| 3-3 | 창세기 1:1의 내용을 확인한다 | "태초에 하나님이 천지를 창조하시니라"가 표시된다 | ☐ |
| 3-4 | 본문을 아래로 스크롤한다 | 모든 절이 순서대로 표시된다 | ☐ |
| 3-5 | 헤더의 카테고리 라벨을 확인한다 | "모세오경" 등 해당 카테고리가 표시된다 | ☐ |

### 테스트 절차 — 책/장 네비게이션

| # | 테스트 항목 | 기대 결과 | 결과 |
|---|-----------|----------|------|
| 3-6 | 상단의 책 이름 칩(예: "창세기")을 탭한다 | 66권 목록이 BottomSheet로 표시된다 | ☐ |
| 3-7 | 목록에서 "요한복음"을 선택한다 | 요한복음 1장이 표시된다 | ☐ |
| 3-8 | 요한복음 3장 16절의 내용을 확인한다 | "하나님이 세상을 이처럼 사랑하사 독생자를 주셨으니..."가 표시된다 | ☐ |
| 3-9 | 상단의 장 번호 칩(예: "1장")을 탭한다 | 장 선택 그리드가 BottomSheet로 표시된다 | ☐ |
| 3-10 | 그리드에서 "3"을 선택한다 | 해당 책의 3장이 표시된다 | ☐ |
| 3-11 | 현재 선택된 장이 그리드에서 강조 표시되는지 확인한다 | 선택된 장이 Sage Green 배경으로 강조된다 | ☐ |
| 3-12 | 시편을 선택한다 | 장 그리드에 150개 장이 표시된다 | ☐ |
| 3-13 | 빌레몬서를 선택한다 | 1장만 표시된다 (1장짜리 책) | ☐ |

## TC-04. AI 상담 (Divine Counsel)

| 항목 | 내용 |
|------|------|
| **기능 ID** | TC-04 |
| **화면** | CounselView |
| **설명** | 사용자 입력에 맞는 성경 구절과 따뜻한 메시지를 매칭하여 제공 |

### 테스트 절차 — 기본 동작

| # | 테스트 항목 | 기대 결과 | 결과 |
|---|-----------|----------|------|
| 4-1 | 상담 탭으로 이동한다 | 상단에 "Divine Counsel" 타이틀, 초기 인사 메시지가 표시된다 | ☐ |
| 4-2 | 추천 질문 칩을 확인한다 | "오늘 위로가 필요해요", "감사 기도를 하고 싶어요" 등 칩 버튼이 표시된다 | ☐ |
| 4-3 | 추천 질문 칩 "오늘 위로가 필요해요"를 탭한다 | 해당 텍스트가 사용자 메시지로 전송되고 AI 응답이 표시된다 | ☐ |

### 테스트 절차 — 키워드 매칭 정확도

| # | 테스트 입력 | 기대 결과 | 결과 |
|---|-----------|----------|------|
| 4-4 | "취업이 안 돼서 힘들어요" | "취업" 카테고리 매칭 → 예레미야 29:11 구절 포함 응답 | ☐ |
| 4-5 | "마음이 불안해요" | "불안" 카테고리 매칭 → 빌립보서 4:6-7 구절 포함 응답 | ☐ |
| 4-6 | "너무 슬퍼요" | "슬픔" 카테고리 매칭 → 시편 34:18 등 위로 구절 포함 | ☐ |
| 4-7 | "외로워요" | "외로움" 카테고리 매칭 → 신명기 31:8 등 동행 구절 포함 | ☐ |
| 4-8 | "화가 나요" | "분노" 카테고리 매칭 → 야고보서 1:19-20 등 포함 | ☐ |
| 4-9 | "감사해요" | "감사" 카테고리 매칭 → 데살로니가전서 5:18 등 포함 | ☐ |
| 4-10 | "용서하기 어려워요" | "용서" 카테고리 매칭 → 마태복음 6:14-15 등 포함 | ☐ |
| 4-11 | "두려워요" | "두려움" 카테고리 매칭 → 디모데후서 1:7 등 포함 | ☐ |
| 4-12 | "소망이 필요해요" | "소망" 카테고리 매칭 → 로마서 15:13 등 포함 | ☐ |
| 4-13 | "직장에서 너무 지쳐요" | "직장 스트레스" 매칭 → 골로새서 3:23-24 등 포함 | ☐ |

### 테스트 절차 — 응답 형태

| # | 테스트 항목 | 기대 결과 | 결과 |
|---|-----------|----------|------|
| 4-14 | AI 응답의 텍스트를 확인한다 | 따뜻한 위로/격려 메시지가 해요체로 표시된다 | ☐ |
| 4-15 | 응답 내 성경 구절 카드를 확인한다 | 구절 참조(예: "예레미야 29:11")와 실제 본문이 카드 형태로 인라인 표시된다 | ☐ |
| 4-16 | 성경 구절 카드의 본문 내용이 정확한지 확인한다 | bible_full.json의 해당 구절과 일치한다 | ☐ |
| 4-17 | "함께 기도해요" 섹션을 확인한다 | 기도 가이드 텍스트가 별도 카드로 표시된다 | ☐ |
| 4-18 | 매칭이 안 되는 메시지를 입력한다 (예: "asdfgh") | 기본 응답("마음을 나눠주셔서 감사해요. 조금 더 자세히...")이 표시된다 | ☐ |

## TC-06. 하단 네비게이션 바

| 항목 | 내용 |
|------|------|
| **기능 ID** | TC-06 |
| **화면** | EdenBottomNav (전체) |
| **설명** | 5개 탭(홈/성경/상담/북마크/설정) 전환 |

### 테스트 절차

| # | 테스트 항목 | 기대 결과 | 결과 |
|---|-----------|----------|------|
| 6-1 | 하단에 5개 탭 아이콘이 표시되는지 확인한다 | 홈, 성경, 상담, 북마크, 설정 아이콘+라벨이 표시된다 | ☐ |
| 6-2 | 현재 탭이 강조 표시되는지 확인한다 | 활성 탭이 Sage Green으로 배경 강조 + 약간 위로 올라간다 | ☐ |
